欢迎来到**梦澄博客**。

这是这个博客的第一篇文章，也是你可以照着改的模板。以后想写新文章，复制一个文章文件夹改改就行。

## 写新文章的步骤

1. 在 `src/content/blog/` 下新建一个文件夹，文件夹名用英文小写加连字符，比如 `my-first-post`
2. 在文件夹里创建 `index.md`
3. 配图放在同一个文件夹里，正文里用 `./` 相对路径引用
4. 提交并推送，网站自动更新

文件夹结构长这样：

```text
src/content/blog/
└── my-first-post/
    ├── index.md
    └── cover.svg
```

## 文章头部信息

每篇文章开头有一段配置信息，格式如下：

```yaml
---
title: 文章标题
description: 一句话摘要，会显示在文章列表卡片上
tags: ['标签一', '标签二']
pinned: false
---
```

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | 必填 | 文章标题 |
| `date` | 必填 | 发布日期，比如 `2026-10-03` |
| `description` | 选填 | 列表卡片上的摘要，也会用作 SEO 描述 |
| `tags` | 选填 | 标签数组，标签页会自动聚合 |
| `draft` | 选填 | 填 `true` 时草稿不显示在列表中，默认 `false` |
| `pinned` | 选填 | 填 `true` 时在列表置顶，默认 `false` |

> 如果字段写错了，构建时会直接报错并告诉你是哪个文件的哪个字段有问题，不用担心悄悄生成坏页面。

## 草稿

写了一半不想发布？在头部加一行：

```yaml
draft: true
```

这篇文章就不会出现在首页列表里了，但依然可以直接通过链接访问，方便你预览。写完记得改回 `false`。
